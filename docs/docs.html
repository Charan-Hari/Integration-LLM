Getting Started

Integration-LLM is a TypeScript library that provides a unified interface for interacting with multiple Large Language Model (LLM) providers. Whether you're using Azure OpenAI, AWS Bedrock, Google Vertex AI, or Ollama, this library simplifies the integration process.

Key Concepts

ChatService: The main facade for sending messages to LLMs

LLMStrategy: The interface that each platform provider implements

LLMFactory: Creates strategy instances for specific models

Registry: Manages and resolves factories

Installation

npm install integration-llm
Note: Currently, this package is available as a development library. For production use, you may need to configure authentication and API keys with your chosen provider.

Basic Usage

1. Register Platform Factories

First, register the available platform factories:

import { registerDefaultFactories } from 'integration-llm';

registerDefaultFactories();

2. Create and Configure ChatService

import { ChatService } from 'integration-llm';

const chatService = new ChatService();

chatService.configure({
  platform: 'azure',
  model: 'gpt-4o-mini'
});

3. Send Messages

const response = await chatService.send('What is machine learning?');

console.log(response.content);
console.log(response.usage.totalTokens);

4. Stream Responses

For streaming responses, use the stream method:

for await (const chunk of chatService.stream('Tell me a story')) {
  process.stdout.write(chunk.content);
}

API Reference

ChatService

The main service class for sending messages to LLMs.

Method Description
configure(config: ProviderConfig) Configure the service with a platform and model
send(prompt: string, options?: ChatOptions) Send a message and get a response
stream(prompt: string, options?: ChatOptions) Stream a response in chunks
getCurrentConfiguration() Get the current configuration

LLMClientBuilder

A fluent API for building and configuring LLM clients:

import { LLMClientBuilder, registerDefaultFactories } from 'integration-llm';

registerDefaultFactories();

const response = await LLMClientBuilder
  .create()
  .withPlatform('google')
  .withModel('gemini-pro')
  .send('What is TypeScript?');

console.log(response.content);

ProviderConfig

Property Type Description
platform string The LLM provider: 'azure', 'bedrock', 'google', 'ollama'
model string The specific model ID for the platform

ChatResponse

Property Type Description
content string The response text from the LLM
usage TokenUsage Token usage information
metadata object Provider-specific metadata

Examples

Example 1: Basic Message

import { ChatService, registerDefaultFactories } from 'integration-llm';

registerDefaultFactories();

async function main() {
  const chat = new ChatService();
  chat.configure({
    platform: 'ollama',
    model: 'llama3.2'
  });

  const response = await chat.send('Hello, how are you?');
  console.log(response.content);
}

main();

Example 2: Runtime Provider Switching

import { ChatService, registerDefaultFactories } from 'integration-llm';

registerDefaultFactories();

async function compareProviders() {
  const chat = new ChatService();
  const prompt = 'Explain quantum computing';

  // Try Azure
  chat.configure({ platform: 'azure', model: 'gpt-4o-mini' });
  const azureResponse = await chat.send(prompt);
  console.log('Azure:', azureResponse.content);

  // Switch to Bedrock
  chat.configure({ platform: 'bedrock', model: 'anthropic.claude-v2' });
  const bedrockResponse = await chat.send(prompt);
  console.log('Bedrock:', bedrockResponse.content);

  // Switch to Google
  chat.configure({ platform: 'google', model: 'gemini-pro' });
  const googleResponse = await chat.send(prompt);
  console.log('Google:', googleResponse.content);
}

compareProviders();

Example 3: Streaming Responses

import { ChatService, registerDefaultFactories } from 'integration-llm';

registerDefaultFactories();

async function streamResponse() {
  const chat = new ChatService();
  chat.configure({
    platform: 'bedrock',
    model: 'anthropic.claude-v2'
  });

  console.log('Response: ');
  for await (const chunk of chat.stream('Write a poem about programming')) {
    process.stdout.write(chunk.content);
  }
  console.log('\n');
}

streamResponse();

Example 4: Custom Platform Registration

import { llmRegistry } from 'integration-llm';
import { CustomPlatformFactory } from './custom-platform-factory';

// Register a custom platform
llmRegistry.registerFactory('custom', new CustomPlatformFactory());

// Now you can use it
const chat = new ChatService();
chat.configure({
  platform: 'custom',
  model: 'your-model'
});

Design Patterns

Strategy Pattern

The LLMStrategy interface defines the contract for all LLM providers:

export interface LLMStrategy {
  sendMessage(prompt: string, options?: ChatOptions): Promise;
  streamMessage(prompt: string, options?: ChatOptions): AsyncIterable;
}

Each platform (Azure, Bedrock, Google, Ollama) implements this interface, allowing the application to switch implementations at runtime without changing client code.

Abstract Factory Pattern

Each platform has a dedicated factory that creates strategy instances:

export interface LLMFactory {
  createClient(modelId: string): LLMStrategy;
}

This decouples object creation from usage, making it easy to add new platforms or modify creation logic.

Adapter Pattern

Each platform's strategy adapts the provider's native API to our unified ChatResponse format:

// Example: Azure Adapter
class AzureStrategy implements LLMStrategy {
  async sendMessage(prompt: string): Promise {
    const nativeResponse = await this.azureClient.createChatCompletion(...);
    return {
      content: nativeResponse.choices[0].message.content,
      usage: {
        promptTokens: nativeResponse.usage.prompt_tokens,
        completionTokens: nativeResponse.usage.completion_tokens,
        totalTokens: nativeResponse.usage.total_tokens
      }
    };
  }
}

Frequently Asked Questions

Q: Do I need API keys to use this library?

A: The library currently includes mock implementations for development and testing. To use it with real LLMs, you'll need to provide credentials for your chosen provider (Azure API key, AWS credentials, Google Cloud credentials, or Ollama endpoint).

Q: Can I use multiple providers in the same application?

A: Yes! You can create multiple ChatService instances or use a single instance and reconfigure it. This is useful for comparing responses from different providers or implementing fallback strategies.

Q: How do I add a new LLM provider?

A: To add a new provider, implement the LLMStrategy interface and create a corresponding factory. Then register it with the llmRegistry.

Q: Is streaming supported?

A: Yes! The stream() method returns an AsyncIterable that yields streaming chunks.

Q: What are the supported models?

A: See the main documentation for the list of supported models per platform. The library is designed to be extensible, so additional models can be added easily.
