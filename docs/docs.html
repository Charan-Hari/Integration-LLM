📖 Getting Started

Integration-LLM allows you to write provider-agnostic code for Azure OpenAI, AWS Bedrock, Google Vertex AI, Ollama, OpenAI, and Anthropic Claude.

Installation

npm install integration-llm

Basic Usage Example

import { ChatService, registerDefaultFactories } from 'integration-llm';

// 1. Register default provider factories
registerDefaultFactories();

// 2. Instantiate ChatService
const chatService = new ChatService();

// 3. Configure provider and model dynamically at runtime
chatService.configure({
  platform: 'ollama', // Options: 'azure', 'bedrock', 'google', 'ollama', 'openai', 'anthropic'
  model: 'llama3.2'
});

// 4. Send request with optional parameters
const response = await chatService.send('Explain the Strategy Pattern.', {
  temperature: 0.7,
  maxTokens: 500
});

console.log('Model:', response.model);
console.log('Response Content:', response.content);
console.log('Prompt Tokens:', response.usage.promptTokens);
console.log('Completion Tokens:', response.usage.completionTokens);

💻 API Reference

1. ChatService

The main facade class for sending messages and streaming completion chunks.

  • configure(config: ProviderConfig): void - Sets active platform & model.
  • send(prompt: string, options?: ChatOptions): Promise<ChatResponse> - Sends prompt and returns structured response.
  • stream(prompt: string, options?: ChatOptions): AsyncIterable<StreamingChunk> - Yields streaming content fragments.

2. LLMClientBuilder

Fluent builder for constructing and calling LLM strategies step by step.

import { LLMClientBuilder } from 'integration-llm';

const response = await new LLMClientBuilder()
  .setPlatform('azure')
  .setModel('gpt-4o')
  .send('Summarize AI strategy.', { temperature: 0.5 });

3. FallbackChatService (Resilience & Failover)

Automatically attempts backup LLMs sequentially if the primary LLM fails or is rate-limited.

import { FallbackChatService, LLMClientBuilder } from 'integration-llm';

const primary = new LLMClientBuilder().setPlatform('azure').setModel('gpt-4o').build();
const secondary = new LLMClientBuilder().setPlatform('ollama').setModel('llama3.2').build();

const resilientService = new FallbackChatService([primary, secondary]);
const response = await resilientService.send('Important prompt');

4. TokenCalculator

Utility function to estimate prompt and completion tokens for billing & monitoring.

import { TokenCalculator } from 'integration-llm';

const tokens = TokenCalculator.estimateTokenCount('Sample text prompt');
const usage = TokenCalculator.createUsage('User prompt', 'Model completion');

🎯 Design Patterns Deep Dive

🔹 Strategy Pattern

Allows swapping underlying LLM providers (Azure, Bedrock, Google, Ollama, OpenAI, Anthropic) dynamically at runtime via a unified LLMStrategy interface.

🔹 Abstract Factory Pattern

Decouples strategy creation logic from application consumption using dedicated factories (e.g. AzureFactory, OllamaFactory).

🔹 Adapter Pattern

Normalizes vendor-specific SDK payloads into a standardized ChatResponse object containing content and usage statistics.

🔹 Facade Pattern

Simplifies configuration and request dispatching into a single clean ChatService entry point.
