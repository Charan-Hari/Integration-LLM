Architecture

Design Patterns at Work

Strategy Pattern: Each LLM platform implements a unified LLMStrategy interface, allowing runtime switching without client code changes.

Abstract Factory Pattern: Dedicated factories create strategy instances for each platform, decoupling creation from usage.

Adapter Pattern: Platform-specific implementations adapt vendor APIs into a unified ChatResponse format.

Supported Platforms:

  • 🔷 Azure OpenAI - gpt-4o, gpt-4o-mini, gpt-35-turbo
  • 🔶 AWS Bedrock - Claude v2, Mistral, Llama 2
  • 🟠 Google Vertex AI - Gemini Pro, Text Unicorn
  • ⚫ Ollama - Llama 3.2, Gemma, Qwen

Configuration

Response

Code Example

import { ChatService, registerDefaultFactories } from 'integration-llm';

registerDefaultFactories();

const chatService = new ChatService();
chatService.configure({
  platform: 'ollama',
  model: 'llama3.2'
});

const response = await chatService.send(
  'Explain the adapter pattern in software design.'
);

console.log(response.content);
