Key Architectural Features

            

                

                    
🔄

                    
Multi-Cloud Strategy

                    
Unified API interface across Azure OpenAI, AWS Bedrock, Google Vertex AI, Ollama, OpenAI, and Anthropic Claude.

                

                

                    
🏗️

                    
Design Patterns

                    
Architected using Strategy, Abstract Factory, Facade, Builder, and Adapter design patterns for clean extensibility.

                

                

                    
⚡

                    
Zero-Downtime Switching

                    
Swap primary LLM providers at runtime without recompiling code or redeploying microservices.

                

                

                    
🛡️

                    
Resilient Failover

                    
Built-in FallbackChatService automatically fails over to backup LLMs if primary endpoints experience downtime.

                

                

                    
🔁

                    
Retry with Backoff

                    
New RetryChatService wraps any strategy with configurable exponential-backoff retries for transient errors.

                

                

                    
🧩

                    
Prompt Templating

                    
New PromptTemplate utility supports {{variable}} interpolation for reusable, type-checked prompts.

                

                

                    
📡

                    
Streaming Responses

                    
Token-by-token stream() API across all six providers for responsive, real-time UIs.

                

                

                    
📊

                    
Token Estimation

                    
Built-in token heuristic calculator for tracking prompt & completion token consumption across platforms.

                

                

                    
📦

                    
Type-Safe TypeScript

                    
100% strict TypeScript definition files, Vitest test suite, and CI/CD GitHub Actions pipeline included.
